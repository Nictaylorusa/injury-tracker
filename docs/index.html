What these numbers are

Stays and games missed are built from the NBA's official injury reports, which teams file before every game, using the public archive in the sportsdataverse project (the hoopR "nba_stats_injury_report" release). For each game and player I take the last version of the report. A game counts as missed when the player is listed Out for an injury, illness, injury-related rest ("Rest – knee management") or return-to-competition reconditioning. G League assignments, personal reasons, suspensions, "not with team" and plain rest are not counted. A stay is a run of consecutive team games listed Out; if a player is listed Questionable or Probable in between, it starts a new stay. Regular season, play-in and playoff games are included. Preseason and summer league are not.

Checks: Haliburton in 2025-26 comes to 82 games and Lillard to 88, matching HoopsMatic's counts. Full-season league totals run about 3–5% above HoopsMatic's, which counts only confirmed roster players.

Limits: "listed Out" is what the team filed, not a medical diagnosis. Games a player missed without being listed are not here. Right now shows each team's report for its next game; the archive can run up to a day behind the NBA's own site.
